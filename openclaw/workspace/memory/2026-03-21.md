### openclaw.json vs models.json 区别
- `openclaw.json`: 全局配置，包含模型、渠道、gateway、插件等所有设置
- `models.json`: agent 专属配置，只针对单个 agent 的模型设置
- openclaw.json 中 `mode: "merge"` 表示全局模型配置会合并到各个 agent
- kimi-k2.5 在 openclaw.json 中已正确配置：`moonshotai/kimi-k2.5`

### Providers vs Models 概念区分
- `/models` 显示的是 providers（提供商）数量
- kimi-k2.5 是 NVIDIA 提供商下的一个模型，不是新的提供商
