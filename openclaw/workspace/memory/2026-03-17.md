## mychecker 项目分析

### 项目位置
`/mnt/disk_0/IC/nsu/uvc/mychecker`

### 项目性质
ONDEC2NSU Checker - UVM 验证组件，用于检查 ONDEC（解码器）到 NSU（NAND 控制器）模块的功能正确性

### 核心架构
- **分组处理**：8 个 plane_pair 分成 2 个独立的 group
  - Group 0: plane_pair[0:3]
  - Group 1: plane_pair[4:7]
  - 每个 group 有独立的 ost_id

### 主要文件
| 文件 | 用途 | 行数 |
|------|------|------|
| mychecker.sv | 主检查器 | ~1048 |
| ondec2nsu_transaction.sv | 事务定义 | ~626 |
| nsu_cpu_transactions.sv | NSU-CPU 事务 | ~598 |
| mychecker_tb.sv | 测试平台 | ~367 |
| 总计 | | 4302 |

### 三步检查流程
1. 打包阶段 - 从 8 个 FIFO 获取 transaction
2. 命令检查 - 按组判断期望响应（deep_read_resp 或 offwbf）
3. 响应检查 - 验证响应正确性
