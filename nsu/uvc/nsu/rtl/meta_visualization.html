📦 模块概述

nsu_write_meta_ctrl 是 NSU (NAND Storage Unit) 的 meta 数据写入控制模块，负责将 meta 数据通过 AXI 接口写入内存。


参数 值 说明
DATA_WIDTH 256 数据位宽
ADDR_WIDTH 34 地址位宽
Plane 数量 8 支持 8 个 plane，分为 2 组 (Group0: 0-3, Group1: 4-7)
Meta 数据格式 128bit × 8 每个 plane 对应 128bit meta 数据

🔄 状态机流程

空闲 IDLE_STATE
→
判断 Group0 JUDGE0_STATE
→
处理 Group0 META_DATA0_STATE
→
判断 Group1 JUDGE1_STATE
→
处理 Group1 META_DATA1_STATE
→
完成 DONE_STATE

📝 Meta 数据结构

每个 plane 的 meta 数据由 4 部分组成，共 128bit：

字段 位宽 来源 说明
meta_data0 32bit Index 7 (bits [31:0]) Meta 数据第 0 部分
meta_data1 8bit Index 8 (bits [7:0]) Meta 数据第 1 部分
meta_data2 32bit Index 9 (bits [31:0]) Meta 数据第 2 部分
meta_data3 8bit Index 10 (bits [7:0]) Meta 数据第 3 部分

拼接示例

wr_meta_data[i]: {meta_data3[i], meta_data2[i], meta_data1[i], meta_data0[i]}
位宽: 128bit = 8bit + 32bit + 8bit + 32bit

📐 AXI 写入长度计算规则

根据 plane 数量和地址对齐情况计算 AXI 突发长度：

Plane 数量 地址[4] = 0 地址[4] = 1 说明
0 或 1 0 0 单个 plane，无需额外 burst
2 0 1 2 个 plane，地址对齐决定长度
3 1 1 3 个 plane，固定长度 1
4 1 2 4 个 plane，地址对齐决定长度

0%

🎭 写掩码 (Write Mask) 计算

根据 plane 数量和地址对齐生成 6bit 掩码：

Plane 数量 地址[4] = 0 地址[4] = 1
1 6'b00_0001 6'b00_0010
2 6'b00_0011 6'b00_0110
3 6'b00_0111 6'b00_1110
4 6'b00_1111 6'b01_1110

Mask 映射到 WSTRB

mask_temp[1] → lm_wmask[31:16] (高 16bit)

mask_temp[0] → lm_wmask[15:0] (低 16bit)

每个 mask bit 扩展为 16bit 的 strobe 信号
