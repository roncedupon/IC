# 位域字段修复总结

## 问题描述

编译报错显示字段名称不匹配：
- Error: Could not find member 'nsu_ost_id' in class 'nsu2cpu_deep_resp_transaction'
- Error: token 'pending_instr_idx' (cross-module reference error)

## 根本原因

`nsu2cpu_deep_resp_transaction` 中**没有** `nsu_ost_id` 字段，而是使用：
- `group0_ost_id`: Group 0 (PP[0:3]) 的 OST ID
- `group1_ost_id`: Group 1 (PP[4:7]) 的 OST ID

而 `ondec2nsu_transaction` 中使用的是 `nsu_ost_id` 字段。

## 字段映射关系

### ondec2nsu_transaction (input)
```systemverilog
rand logic [4:0] nsu_ost_id;  // 每个 transaction 一个 ost_id
```

根据约束，group 内的 ost_id 一致：
- tr[0].nsu_ost_id = tr[1].nsu_ost_id = tr[2].nsu_ost_id = tr[3].nsu_ost_id (Group 0)
- tr[4].nsu_ost_id = tr[5].nsu_ost_id = tr[6].nsu_ost_id = tr[7].nsu_ost_id (Group 1)

### nsu2cpu_deep_resp_transaction (output)
```systemverilog
rand bit [4:0] group0_ost_id;  // Group 0 (PP[0:3]) 的 OST ID
rand bit [4:0] group1_ost_id;  // Group 1 (PP[4:7]) 的 OST ID
```

### nsu2offwbf_transaction (output)
```systemverilog
rand logic [4:0] nsu_ost_id;  // 与 ondec2nsu_transaction 一致
```

## 修复方案

### 1. check_deep_read_resp 中的 ost_id 匹配

**修复前（错误）**:
```systemverilog
if (cfg.nsu_ost_id == resp.nsu_ost_id) begin  // ❌ resp 没有 nsu_ost_id 字段
```

**修复后（正确）**:
```systemverilog
logic [4:0] resp_ost_id;

// 根据 group_id 获取 resp 中对应的 ost_id
if (gid == 0) begin
    resp_ost_id = resp.group0_ost_id;
end else begin
    resp_ost_id = resp.group1_ost_id;
end

// 检查 ost_id 是否匹配
if (cfg.nsu_ost_id == resp_ost_id) begin
    matched_gid = gid;
```

### 2. 测试平台中的字段名称

**修复前（错误）**:
```systemverilog
deep_resp.nsu_ost_id = 5'h01;  // ❌ 没有这个字段
```

**修复后（正确）**:
```systemverilog
deep_resp.group0_ost_id = 5'h01;  // ✓ Group 0 的 ost_id
deep_resp.group1_ost_id = 5'h02;  // ✓ Group 1 的 ost_id
```

## 关键点总结

1. **Group 独立性**: 8 个 plane_pair 分成 2 个 group，每个 group 有独立的 ost_id
2. **字段命名差异**: 
   - ondec: `nsu_ost_id` (每个 PP 一个)
   - deep_resp: `group0_ost_id`, `group1_ost_id` (每个 group 一个)
   - offwbf: `nsu_ost_id` (与 ondec 一致)
3. **匹配逻辑**: 根据 group_id 选择对应的 ost_id 字段进行比较
4. **约束保证**: ondec group 约束保证 group 内 ost_id 一致
